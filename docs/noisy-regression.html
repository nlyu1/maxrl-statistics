Noisy regression

A small linear problem, presented as a sequence of numerical tokens

The noisy-regression problem, the behavior of its variables, quantization and autoregressive prediction, followed by the current experiment and prompt formats.
Published

September 12, 2026

Each training example is a miniature regression problem. A hidden vector specifies a linear rule; the model sees several noisy input–output pairs from that rule and must predict the output at one new input. The rule changes from example to example. A small transformer learns from many such problems how to use the observations inside each prompt.

1 The continuous problem

Let \(d\) be the input dimension, \(n\) the number of context observations, and \(\sigma\) the noise standard deviation. To generate one example:

  1. Draw a hidden coefficient vector \(w\sim\mathcal N(0,I_d/d)\).
  2. Independently draw \(x_1,\ldots,x_n,x_*\sim\mathcal N(0,I_d)\).
  3. Draw independent noises \(\epsilon_1,\ldots,\epsilon_n,\epsilon_*\sim\mathcal N(0,\sigma^2)\), independent of \(w\) and all inputs.
  4. Form the observations and query target:

\[ y_i=w^\top x_i+\epsilon_i,\qquad s_*=w^\top x_*,\qquad y_*=s_*+\epsilon_*. \tag{1}\]

The context is \(D=\{(x_i,y_i)\}_{i=1}^n\); the query input is \(x_*\). The model receives their quantized representations and learns a distribution over the quantized noisy answer \(y_*\). We also evaluate against the clean signal \(s_*\). Neither \(w\), the noise values, nor the unrounded numbers are exposed to the model. Noise affects outputs, not the underlying input coordinates. Data generator.

There are two different sample counts: \(n\) observations help infer the rule within one prompt, whereas \(M\) training examples teach the transformer across many independently drawn rules. Increasing \(M\) does not give a held-out prompt more observations. The context and query share \(w\) within a prompt, so their outputs are not independent after marginalizing over that shared vector.

1.1 From the latent rule to the observed output

The latent rule \(w\) and input \(x\). The direction of \(w\) determines which input directions affect the output, while its norm determines the amplitude of that dependence. Under the prior, \(d\|w\|^2\sim\chi_d^2\), so

\[ \mathbb E\|w\|^2=1,\qquad \operatorname{Var}(\|w\|^2)=\frac{2}{d}. \]

Thus the task amplitude varies substantially at small \(d\) and concentrates as dimension grows. Independently, the input has \(\mathbb E\|x\|^2=d\). Scaling the coefficient prior by \(1/d\) compensates for the increasing number of input coordinates; it does not normalize each realized vector to a fixed norm.

The clean signal \(s=w^\top x\). Within a task, the projection of a fresh Gaussian input onto the fixed direction \(w\) gives

\[ s\mid w\sim\mathcal N(0,\|w\|^2). \]

If instead the input is fixed and the rule is unknown, then \(s\mid x\sim\mathcal N(0,\|x\|^2/d)\). Larger-norm queries therefore have a wider prior distribution of possible outputs. Averaging over both inputs and rules yields

\[ \mathbb E[s]=0,\qquad \operatorname{Var}(s)=\mathbb E_w\|w\|^2 =\operatorname{tr}(I_d/d)=1. \tag{2}\]

Across tasks, \(s\) is a Gaussian variance mixture: different rules supply different conditional variances. Its shape need not be Gaussian even though its mean and variance match a standard Gaussian. To characterize it, write \(w_j=g_j/\sqrt d\) for independent standard normal \(g_j\). The product \(g_jx_j/\sqrt d\) has characteristic function \((1+t^2/d)^{-1/2}\), so

\[ \varphi_s(t)=\mathbb E[e^{its}] =\left(1+\frac{t^2}{d}\right)^{-d/2},\qquad \mathbb E[s^4]=3+\frac{6}{d}. \tag{3}\]

The excess kurtosis \(6/d\) captures the heavier tails at finite dimension. As \(d\) grows, \(\varphi_s(t)\) tends to \(e^{-t^2/2}\) and \(s\) approaches a standard Gaussian. A prior supported on unit-norm \(w\) would give an exactly standard-Gaussian clean marginal for every dimension, but that is a different generative model.

The noisy output \(y=s+\epsilon\). Independent additive noise broadens the clean signal without changing its mean. Conditional on both \(w\) and \(x\), it is centered on the linear rule:

\[ y\mid w,x\sim\mathcal N(w^\top x,\sigma^2). \]

Varying inputs within one task gives \(y\mid w\sim\mathcal N(0,\|w\|^2+\sigma^2)\); holding the input fixed instead gives \(y\mid x\sim\mathcal N(0,\|x\|^2/d+\sigma^2)\). Across tasks, the output law is the convolution of the clean variance mixture with \(\mathcal N(0,\sigma^2)\), with

\[ \mathbb E[y]=0,\qquad \operatorname{Var}(y)=1+\sigma^2,\qquad \mathrm{SNR}=\frac{\operatorname{Var}(s)}{\operatorname{Var}(\epsilon)} =\frac{1}{\sigma^2}. \tag{4}\]

This normalization makes population SNR directly controllable through \(\sigma\), independently of \(d\). Here SNR is a variance ratio; the standard-deviation ratio is \(1/\sigma\), and the decibel value is \(-20\log_{10}\sigma\). An individual task has SNR \(\|w\|^2/\sigma^2\). The signal variance \(1\) describes variation of the regression target across the population; even perfect knowledge of \(w\) and \(x_*\) leaves the fresh noisy target with irreducible variance \(\sigma^2\).

1.2 The context and posterior prediction

Each context observation constrains the component of \(w\) along its input direction. Observations spanning different directions help identify the whole rule; repeated observations along nearly the same direction leave other components uncertain. The level sets \(w^\top x=c\) are hyperplanes perpendicular to \(w\).

Let \(X\) contain the context inputs as rows and \(y=(y_1,\ldots,y_n)^\top\). Integrating out the shared rule gives \(y\mid X\sim\mathcal N(0,XX^\top/d+\sigma^2I_n)\). Thus the outputs are coupled through the inner products of their inputs, even though their injected noises are independent.

With continuous observations, the posterior over the hidden rule is exactly Gaussian, \(w\mid D\sim\mathcal N(\mu,\Sigma)\), where

\[ \Sigma=(dI_d+X^\top X/\sigma^2)^{-1},\qquad \mu=\Sigma X^\top y/\sigma^2, \] \[ s_*\mid D,x_*\sim\mathcal N(x_*^\top\mu,\;x_*^\top\Sigma x_*),\qquad y_*\mid D,x_*\sim\mathcal N(x_*^\top\mu,\;x_*^\top\Sigma x_*+\sigma^2). \tag{5}\]

The first variance describes uncertainty about the hidden rule; the extra \(\sigma^2\) is fresh query noise. When \(X^\top X\approx nI_d\), the average clean predictive variance is approximately \(d\sigma^2/(n+d\sigma^2)\). This is an intuition for a well-covered design, not an exact finite-sample identity. Increasing \(d\) at fixed \(n\) makes inference harder even though signal variance stays one. For \(n<d\), noiseless observations cannot determine all directions of \(w\).

The implementation uses this continuous-data posterior as an optimistic reference. Applying the same formula to decoded token centers gives a plug-in ridge approximation, not the exact Bayesian answer to the quantized-input problem: rounding and clipping change the observation model. Reference implementations.

2 Turning numbers into tokens

2.1 The scalar codec

Choose a range \([-A,A]\) and \(K\geq2\) equally spaced centers, including both endpoints:

\[ \Delta=\frac{2A}{K-1},\qquad c_k=-A+k\Delta,\quad k=0,\ldots,K-1. \]

A scalar \(z\) maps to its nearest center; midpoint ties go to the larger index and tails saturate at an endpoint. Equivalently, in exact arithmetic,

\[ q(z)=\operatorname{clip}_{[0,K-1]} \left(\left\lfloor\frac{z+A}{\Delta}+\frac12\right\rfloor\right). \tag{6}\]

The resulting index must then be represented as tokens. When \(K=B^m\), it can be written as \(m\) base-\(B\) digits,

\[ q=\sum_{j=1}^m a_jB^{m-j},\qquad a_j\in\{0,\ldots,B-1\}. \]

Treating each digit as a vocabulary entry trades a smaller numerical vocabulary for a longer autoregressive answer. Using a single token for each center instead requires \(K\) numerical vocabulary entries. These choices change the sequence-learning problem even when the underlying scalar grid is unchanged.

In the unclipped interior, the maximum rounding error is \(\Delta/2\). For a symmetric grid with even \(K\), zero lies between the central centers and is rounded upward by the tie rule; with odd \(K\), zero is itself a center.

2.2 Quantization regimes and why they matter

The useful comparison is among noise scale \(\sigma\), grid spacing \(\Delta\), and range \(A\). The labels below describe a continuous crossover, not sharp phase transitions.

Regime Scale relation Consequence
Noise resolved by the grid \(\Delta\ll\sigma\) Many output bins lie inside one noise standard deviation. Bin probabilities resolve the continuous noise distribution.
Noise and grid comparable \(\Delta\approx\sigma\) Several neighboring answers can be plausible; bin boundaries materially affect the label distribution.
Noise mostly hidden by the grid \(\sigma\ll\Delta\) Away from boundaries, changing the noise often leaves the answer tokens unchanged. Near a midpoint, even tiny noise can change the bin.
Saturation in the tails \(|z|>A\) The codec loses tail magnitude. This can coexist with any of the three noise regimes.

The justification comes from bin probabilities. For a known clean output \(s\), define interior boundaries \(b_k=(c_{k-1}+c_k)/2\) for \(k=1,\ldots,K-1\), with \(b_0=-\infty\) and \(b_K=+\infty\). Then

\[ \Pr(q(s+\epsilon)=k\mid s) =\Phi\!\left(\frac{b_{k+1}-s}{\sigma}\right) -\Phi\!\left(\frac{b_k-s}{\sigma}\right). \tag{7}\]

At an interior bin center, the probability of staying in that bin is \(2\Phi(\Delta/(2\sigma))-1\). At a midpoint, the two adjacent bins each receive nearly half the mass when \(\sigma\ll\Delta\). Thus “small noise” does not mean “deterministic tokens” uniformly over all clean signals.

The familiar uniform-rounding approximation assigns standard deviation \(\Delta/\sqrt{12}\) and variance \(\Delta^2/12\) to rounding error. It assumes a smooth distribution across bins and negligible clipping; it is a scale comparison, not an independent-noise model guaranteed by the codec and not a universal MSE floor for the learned predictor.

Input quantization matters too. Writing \(\tilde x=x+\delta_x\) and \(\tilde y=y+\delta_y\) gives

\[ \tilde y=w^\top\tilde x+\epsilon+\delta_y-w^\top\delta_x. \]

Under the same rough independent-rounding approximation, the extra context residual variance conditional on \(w\) is \((1+\|w\|^2)\Delta^2/12\). Query-input rounding adds another source of uncertainty when evaluating against a continuous target. The exact token-conditioned problem must account for the input and output intervals jointly.

The finite range is a second tradeoff. A wider range clips less, but makes \(\Delta\) larger if \(K\) stays fixed. A standard-Gaussian input coordinate exceeds the range with probability \(2\Phi(-A)\); the output’s clipping probability must instead use its own marginal distribution, including the noise if the target is noisy. Landing in an endpoint bin does not necessarily mean the raw number was outside \([-A,A]\): the endpoint bin begins half a step inside the range.

3 Learning and evaluating a predictor

3.1 Autoregressive prediction

Serialize the quantized context and query input into a prompt \(P\). The numerical answer is a digit sequence \(a_{1:m}\). A causal transformer assigns it probability

\[ p_\theta(a_{1:m}\mid P) =\prod_{j=1}^m p_\theta(a_j\mid P,a_{1:j-1}). \]

Learned embeddings represent the numerical and structural tokens. Attention lets each position use earlier tokens, while positional information preserves the order of observations, coordinates and digits. Later answer digits can depend on earlier answer digits as well as on the entire prompt. During inference, the model’s parameters stay fixed: adapting to a new hidden rule happens through the activations produced by its context, not through an optimizer update for that prompt. This gives the model a way to approximate context-dependent regression, without requiring it to explicitly output \(w\) or implement the analytic Bayesian solution.

Teacher forcing supplies the correct preceding answer digits during training, and the causal mask prevents access to future digits. The answer negative log-likelihood is \(-\sum_{j=1}^m\log p_\theta(a_j\mid P,a_{1:j-1})\). Context tokens act as conditioning information and receive no direct loss. A format with an explicit answer terminator can add a separate termination loss.

3.2 Evaluation on the scalar grid

For a grid small enough to enumerate, the complete answer distribution gives a decoded mean \(\hat y=\sum_{k=0}^{K-1}p_\theta(k\mid P)c_k\). Unlike an individual decoded answer, this mean can lie between grid centers.

MSE compares the mean with the continuous clean target \(s_*\) or noisy target \(y_*\). NLL scores the probability of the corresponding quantized target bin. For \(R\) independent answer samples, exact pass@\(R\) is \(1-[1-p_\theta(q(\mathrm{target})\mid P)]^R\), when success means matching that bin. These metrics answer different questions: predicting a continuous mean accurately and assigning high probability to one discrete bin need not rank predictors identically.

The continuous Bayesian reference has access to more precise information than the transformer. A gap to that reference therefore includes information lost at tokenization, as well as any error in learning to use the context. Finite context, query noise, input rounding and clipping can all contribute uncertainty, even when the population SNR is large.

4 The current experiment

The canonical specification below uses a 10M-example training pool, batch size 1,024, 20K optimizer updates, learning rate \(10^{-4}\) with 200 warmup updates, and \(d=2\), \(\sigma=0.25\), \(n=64\). It uses the delimited prompt; Section 5 compares it with the legacy format. The interactive figures in this section illustrate the specified data-generating process. They are not measurements from a trained model or records extracted from the training pool.

4.1 Configuration

4.2 Signal distribution at two dimensions

For \(d=2\), Equation 3 reduces to \(\varphi_s(t)=(1+t^2/2)^{-1}\), the characteristic function of a Laplace distribution:

\[ s\sim\operatorname{Laplace}\!\left(0,\frac{1}{\sqrt 2}\right),\qquad p(s)=\frac{1}{\sqrt 2}\exp(-\sqrt 2|s|). \tag{8}\]

The clean population signal still has variance one, while the individual task variance \(\|w\|^2\) varies considerably: at \(d=2\), its variance is also one. With \(\sigma=0.25\), the population SNR is \(16\), the signal-to-noise standard-deviation ratio is \(4\), and the decibel value is approximately \(12.04\) dB. The noisy marginal is a convolution of the Laplace law above with a Gaussian of variance \(0.0625\), giving total output variance \(1.0625\).

4.3 Numerical resolution and clipping

Every input coordinate and output uses 256 centers on \([-4,4]\), so \(\Delta=8/255\approx0.0313725\). An index is represented by two base-16 digit tokens, \(q=16a+b\). Their visible names are 0–9, A–F; these are vocabulary entries, not characters passed through a text tokenizer. This gives 256 possible scalar answers with a small digit vocabulary, a short autoregressive answer, and a distribution small enough to enumerate. The range and resolution are experimental design choices, not a claim of optimal quantization.

The codec searches stored midpoints to handle floating-point ties consistently and rejects nonfinite values. For example, \(1\mapsto159\mapsto\texttt{9 F}\) and decodes to \(252/255\approx0.988235\). Zero lies between centers 127 and 128, so \(0\mapsto\texttt{8 0}\) and decodes to \(4/255\approx0.015686\). There is no exact zero center, and the maximum interior rounding error is \(\Delta/2\approx0.015686\). Scalar codec.

At \(\sigma=0.25\), \(\Delta/\sigma\approx0.1255\): one noise standard deviation spans about eight bins, so the grid resolves the injected noise. The uniform-rounding scale is \(\Delta/\sqrt{12}\approx0.009056\), with variance \(\Delta^2/12\approx8.20\times10^{-5}\), about \(0.131\%\) of the injected noise variance. The caveats in Section 2 apply: this is a scale comparison, not a calibrated error floor.

At \(A=4\), a standard-Gaussian input coordinate lies outside the range with probability about 0.00633%. For the \(d=2\) clean signal, Equation 8 instead gives

\[ \Pr(|s|>4)=e^{-4\sqrt2}\approx0.3493\%. \]

A standard-Gaussian tail calculation would therefore understate output clipping. Noisy-output clipping must use the Laplace–Gaussian convolution at \(\sigma=0.25\), rather than the clean-signal tail above. Actual saved-pool clipping fractions are recorded in dataset metadata; these count raw range exceedances, not all endpoint-bin assignments.

4.4 Transformer architecture

The predictor is a Qwen2 decoder-only transformer initialized from scratch, with four blocks and hidden width 128. These 128 hidden features are learned token representations; they are distinct from the regression input dimension \(d=2\). The model receives a sequence of digit and marker IDs, not a two-dimensional numerical tensor supplied directly to a regression head.

The input embedding matrix has shape \(24\times128\), assigning a learned vector to each vocabulary entry. Each transformer block applies attention and a feed-forward network with residual connections and normalization before each operation. Writing \(H\) for the sequence of hidden states, a block has the form

\[ \begin{aligned} U&=H+\operatorname{Attention}(\operatorname{RMSNorm}(H)),\\ H_{\mathrm{next}}&=U+\operatorname{MLP}(\operatorname{RMSNorm}(U)). \end{aligned} \tag{9}\]

Attention reads the preceding sequence. There are four query heads and two key/value heads, each with head dimension \(128/4=32\). In this grouped-query arrangement, each key/value head is shared by two query heads. A head forms a weighted combination of values at accessible positions; the causal mask lets the current token attend to earlier tokens and itself. The four head outputs are concatenated and projected back to width 128. Attention is full-context, with a capacity of 1,024 tokens, no sliding window and no attention dropout.

Position and normalization preserve usable sequence information. Rotary positional embeddings (RoPE, base parameter \(10^6\)) rotate queries and keys according to token position, allowing attention scores to depend on relative position without adding a learned positional-embedding table. RMSNorm rescales each hidden vector using its root-mean-square magnitude and a learned scale, with numerical epsilon \(10^{-6}\). The residual connections retain the incoming representation while each sublayer adds an update.

The feed-forward network transforms each position separately. Two projections map the 128-dimensional state to width 512. One passes through SiLU and gates the other by elementwise multiplication; a third projection maps the result back to width 128:

\[ \operatorname{MLP}(z) =W_{\mathrm{down}}\!\left[ \operatorname{SiLU}(W_{\mathrm{gate}}z)\odot(W_{\mathrm{up}}z) \right]. \]

After the four blocks, a final RMSNorm precedes the vocabulary projection. The output projection shares the input embedding matrix, so a normalized hidden vector \(h_t\) produces logits \(Eh_t\) for \(E\in\mathbb R^{24\times128}\). The hidden state at the query’s final [Y] predicts the first answer digit; the state after that digit predicts the second. The following state predicts [EOS] in the new format. The digit and termination losses use the output restrictions described in Section 5.

The 24-token model has 988,288 trainable parameters. All embeddings and transformer weights are learned from these synthetic problems; using the Qwen2 architecture does not imply using pretrained Qwen2 weights. The legacy 20-token version has 987,776 parameters because its tied embedding matrix has four fewer rows. Model configuration and construction, Qwen2 block implementation.

4.5 Optimization and frozen data

There are \(20{,}000\times1{,}024=20{,}480{,}000\) training presentations, equivalent to 2.048 passes through the 10M pool: two full passes, then 480,000 examples from a third shuffle. Reshuffling does not redraw \(w\), inputs, noises, or targets. The experiment does not set fixed generation or training seeds; saving a pool freezes its actual draws, and checkpoints retain RNG state for resumption.

Number updates from \(s=1\) and let \(W=200\). The canonical scheduler uses

\[ \eta_s= \begin{cases} 10^{-5}+(10^{-4}-10^{-5})\dfrac{s-1}{W-1}, & 1\leq s\leq W,\\[6pt] 10^{-4}, & W<s\leq20{,}000. \end{cases} \tag{10}\]

Update 1 uses exactly \(10^{-5}\), update 200 reaches \(10^{-4}\), and updates 201 through 20,000 retain that rate. “Constant after warmup” refers to the learning rate; AdamW’s weight decay remains active. The effective batch and microbatch are both 1,024, so each update uses one forward/backward pass. BF16 is used for the forward computation, with FP32 master weights, optimizer states and loss computation.

4.6 Explore a two-dimensional task

Here \(w=(w_1,w_2)\) gives the two slopes of the plane \(s=w_1x_1+w_2x_2\). Equal-output points lie on parallel lines in the input plane, perpendicular to \(w\). Observations in different directions constrain both slopes.

In Figure 3, the left panel keeps both input coordinates visible. The colored background is the hidden clean rule, circles are noisy observations, and the star is the query. The right panel shows the posterior over the two coefficients, so you can see how the context identifies the plane. At low noise its uncertainty region becomes very small; its axes automatically zoom.

Try reducing noise to \(0.001\), reducing the context to one or two observations, rotating the hidden rule, and showing quantized inputs. Changing \(n\) reuses a prefix of the same observations; changing noise rescales the same noise draws. This makes the effect of each control easier to compare. Drawing a new task samples a fresh \(w\) from the stated prior; manually changing its angle or norm explores a chosen rule conditional on that \(w\).

The geometric controls are explanatory counterfactuals. The canonical launchers use \(d=2\) and \(n=64\); other dimensions require matching dataset layouts and sufficient model sequence capacity. The full 64-observation prompt below always uses a separate fixed illustrative draw with the canonical codec.

5 Concrete prompt formats

There is no English instruction in the actual training input. The displayed spaces and line breaks below make tokens readable; they are not extra tokens. Each digit and each bracketed marker is one vocabulary entry. The hidden coefficient vector is shared by all observations in a prompt and omitted from the sequence.

5.1 A concrete miniature example

For readability, first use just three observations, with the illustrative hidden rule \(w=(0.6,-0.8)\) and hand-chosen noises at the \(\sigma=0.25\) scale. Both prompt formats below use the current \([-4,4]\) scalar grid:

Context 1 \((1,0)\) \(0.6\) \(0.25\) \(0.85\) 9 F 8 0; 9 B
Context 2 \((0,1)\) \(-0.8\) \(-0.25\) \(-1.05\) 8 0 9 F; 5 E
Context 3 \((-1,1)\) \(-1.4\) \(0.125\) \(-1.275\) 6 0 9 F; 5 7
Query \((0.5,-0.5)\) \(0.7\) \(0.25\) \(0.95\) 8 F 7 0; 9 E

[Y] is the query; there is no distinct query marker, observation terminator or EOS. The vocabulary is 16 digits plus [X], [Y], [PAD], [BOS], totaling 20 tokens. The four-layer model has 987,776 parameters. Legacy codec.

5.1.2 New: explicit coordinate and observation boundaries

The same numerical example as a new-format prompt:

[BOS]
[X] 9 F [SEP] 8 0 [Y] 9 B [EOO]
[X] 8 0 [SEP] 9 F [Y] 5 E [EOO]
[X] 6 0 [SEP] 9 F [Y] 5 7 [EOO]
[QUERY] [X] 8 F [SEP] 7 0 [Y]

Supervised continuation:

9 E [EOS]

[SEP] separates coordinates within \(x\); [EOO] ends a complete observed \((x,y)\) pair. [QUERY] announces the held-out input, and [EOS] terminates its answer. Each observation now takes ten tokens. The vocabulary is 16 digits plus [X], [SEP], [Y], [EOO], [QUERY], [PAD], [BOS], [EOS], totaling 24 tokens. These extra four embeddings account for the parameter increase of \(4\times128=512\). Delimited codec.

Explicit boundaries make the structure available through dedicated tokens instead of only fixed positions. That is an architectural motivation, not evidence that the new format learns better. It also lengthens the sequence and adds a termination loss, so a comparison should account for both effects. The examples here hold the numerical grid and observations fixed to isolate syntax; comparing trained models additionally requires controlling pool size, noise and optimization budget.

5.2 Lengths and the training objective

At \(d=2\), \(n=64\) Legacy New
Context block \(64\times8=512\) \(64\times10=640\)
BOS plus query prefix \(1+6=7\) \(1+8=9\)
Prompt, through the query [Y] 519 tokens 649 tokens
Supervised continuation 2 answer digits 2 answer digits + [EOS]
Complete training sequence 521 tokens 652 tokens

Teacher forcing supplies the complete sequence during training, but the causal mask prevents seeing future tokens. Context values serve as conditioning information and receive no loss. If the two answer digits are \(a,b\), the answer loss is

\[ \mathcal L_{\mathrm{answer}} =-\log p_\theta(a\mid\text{prompt}) -\log p_\theta(b\mid\text{prompt},a). \]

Both answer softmaxes are restricted to the 16 digit IDs. The new format additionally trains \(-\log p_\theta(\texttt{[EOS]}\mid\text{prompt},a,b)\) using the full 24-token vocabulary. The optimization loss sums the applicable token terms, then averages over examples. Reported answer NLL remains the two-digit quantity for comparability. No loss is applied to [SEP], [EOO] or the other prompt markers. Loss implementation.
