Continuously updated research progress on the rollout-likelihood generalization of maximum likelihood reinforcement learning.

Theory:

  • Theory — MaxRL as a compute-indexed truncation of log-likelihood, per-rollout reweighting, and the generalized leave-one-out estimator.
  • Gradient Estimator — numerically stable \(O(BRD)\) computation of the leave-one-out weights via prefix-suffix scans of elementary symmetric polynomials.

Experiments:

  • Regression: bag of words — noise-robustness in the zero-step sampling setting. WIP.
  • Regression: corpus regression — same zero-step setting on natural-language prefixes. WIP.
  • Regression: DAG-reasoning — reasoning advantage and rollout efficiency. Not started.

The bag-of-words (BoW) setup isolates noise-robustness of SL, GRPO, and MaxRL in a zero-step rollout setting: the model sees a single prompt and predicts a scalar target with no sequential reasoning. There are three versions of the dataset:

  1. Homogeneous hardness: a single, global signal-to-target corr \(\rho\).
  2. Unlearnable heteroskedasticity: global signal corr \(\rho\); random by-row noise variability.
  3. Learnable heteroskedasticity: global signal corr \(\rho\); semantically learnable by-semantic-word noise variability (some words are harder to learn than others).

TL; DR

No advantage of SL / MaxRL over GRPO in the BoW setup, in either homogeneous or heterogeneous settings.

Dataset

Homogeneous baseline

See src/data/bag_of_words.py.

Each prompt is \(L\) words sampled iid from a mixture of semantic words, which carries signal, and auxiliary words, which are pure fillers. The target is a noise-corrupted linear function of word content, parameterized by the correlation between signal and target \(\rho \in (0, 1]\).

7-word vocabulary. Semantic words map to integer values centered at zero:

grim bad poor fair good great perfect
\(-3\) \(-2\) \(-1\) \(0\) \(+1\) \(+2\) \(+3\)

The 256 auxiliary words (common function words: the, a, and, if, because, …) carry value 0. We also define variants with more (e.g. \(11\), \(15\)) semantic words.

Sampling distribution. Semantic words share mass \(1 - \alpha\) (where \(\alpha\) = aux_words_ratio), shaped by a power-law centered on the neutral word “fair”: \(p_i \propto (1 + |i - \text{center}|)^{-\gamma}\). Auxiliary words uniformly split mass \(\alpha\).

Target generation. Given a prompt of length \(L\): \[ \text{signal} = \frac{\rho}{\sigma\sqrt{L}} \sum_{i=1}^L v_i, \qquad \text{target} = \text{signal} + \mathcal{N}(0, \sqrt{1 - \rho^2}) \] where \(\sigma\) is the per-token standard deviation under the full mixture (zero mean by symmetry). By construction \(\text{Var}(\text{target}) = 1\) and \(\text{corr}(\text{signal}, \text{target}) = \rho\).

Word-level heteroskedasticity (learnable)

We propose another heteroskedastic variation where hardness is tied to word content, so it is in principle recoverable from the prompt. Semantic words are ranked by \(|v(w)|\) and assigned a quantile \(q(w) \in (0, 1)\); auxiliary words carry zero hardness. The dataset is parameterized by global signal-to-target correlation \(\rho\), and a difficulty skew snr_halflife_in_word_quantile

NoteConstruction details

The raw per-word multiplier is \[ \tilde a(w) \;=\; \begin{cases} 2^{(q(w) - 1/2)\,/\,h_{\text{word}}} & w \text{ semantic},\\ 0 & w \text{ auxiliary}, \end{cases} \] with \(h_{\text{word}}\) = snr_halflife_in_word_quantile. For a prompt \(x = (w_1, \dots, w_L)\) the prompt-level multiplier is the per-token RMS \[ \tilde a(x)^2 = \frac{1}{L} \sum_{j=1}^{L} \tilde a(w_j)^2, \qquad a(x) = \tilde a(x) \,/\, \sqrt{\mathbb{E}_{w \sim p}[\tilde a(w)^2]}, \] so that \(\mathbb{E}[a(x)^2] = 1\) under the prompt distribution. Targets still preserve the global correlation \(\rho\): \[ \text{target}(x) = \text{signal}(x) + \sqrt{1-\rho^2}\, a(x)\, \varepsilon, \]

Preamble / ramble on MLE

Maximum likelihood estimation (MLE) is a near-axiomatic principle: given data and a parametric family, choose parameters that maximize the probability (likelihood) of observed data. Given the ubiquity of MLE, it’s surprising that maximum-likelihood RL is this recent.

  • Classification is MLE: data-label pairs \((x, y) \sim \rho\), model \(p_\theta(y \mid x)\).
  • Regression is MLE: MSE corresponds to Gaussian noise MLE; L1 corresponds to Laplace noise MLE.
  • Diffusion (score-matching) is MLE, as shown in this post.

Why do we supervise with cross-entropy \(\mathbb E \log p_\theta(y\mid x)\) rather than accuracy-like \(\mathbb E\,p_\theta(y\mid x)\)? One mechanistic lens is the gradient: \[ \nabla_\theta \log p_\theta(y\mid x) = \frac{1}{p_\theta(y\mid x)}\,\nabla_\theta p_\theta(y\mid x). \] So difficult cases (small \(p_\theta\)) get amplified by \(1/p_\theta\).

Maximum likelihood upweights difficult samples aggressively, updating the model on the frontier of its understanding.

Addendum: I would not over-interpret this as the principle itself. It’s a side-effect interpretation. The principle is still MLE. One canonical reading comes from information theory, where MLE is a compression objective that minimizes expected code length under the model. In this lens, each example contributes \(-\log p_\theta(y\mid x)\) nats of surprise. Hard examples are expensive in description length, so ML naturally prioritizes optimization there.

Formulation, notation

Start in the standard LLM-RL latent-generation setting.

  • Data: \((x, y) \sim \rho\).
  • Policy/sequence model: \(z \sim m_\theta(\cdot \mid x)\), where \(z\) is a rollout.
  • Rollout evaluation: decode/postprocess \(z\) into a prediction; compare to target \(y\).

In binary reasoning with verifier, the typical objective is \[ J_{\mathrm{RL}} = \mathbb E_{(x,y)\sim\rho}\,\mathbb E_{z\sim m_\theta(\cdot\mid x)}\,\mathbf 1[\hat y(z)=y]. \]

So far this is standard RL setup. Now the useful abstraction.

  • A rollout \(z\) defines a predictive distribution \(\hat P(\cdot\mid z)\) over labels/targets.
  • Define per-rollout likelihood \[ l(y,z) := \hat P(y\mid z). \]
  • Marginalize over rollouts: \[ \begin{equation} p_\theta(y\mid x) := \mathbb E_{z\sim m_\theta(\cdot\mid x)} l(y,z). \label{eq:marginal-likelihood} \end{equation} \]
  • Score function: \[ \begin{equation} S(x,z) := \nabla_\theta \log m_\theta(z\mid x). \label{eq:score} \end{equation} \]

This score vector is almost always the only intermediate through which policy parameters \(\theta\) touch policy-gradient objectives. Most algorithms differ mainly in how they reweight or shift these score vectors. Unpacking the latent-variable formulation already goes 60% of the way toward understanding this post; note that it subsumes supervised maximum likelihood when sampling is trivial.

Direct RL as a maximum-likelihood approximation

The maximum-likelihood objective (for our latent-generation likelihood) is \[ J(\theta)=\mathbb E_{(x,y)\sim\rho}\,\log p_\theta(y\mid x) =\mathbb E_{(x,y)\sim\rho}\,\log\mathbb E_{z\sim m_\theta(\cdot\mid x)} l(y,z). \] This is the exact analogue of cross-entropy: the log is outside the expectation because \(p_\theta(y\mid x)\) is a marginal likelihood.

Binary reasoning setup

In the binary reasoning setup, typical reward is the expected pass rate: \[ J_{\mathrm{pass}} = \mathbb E_{(x,y)\sim\rho} \,\mathbb E_{z\sim m_\theta(\cdot\mid x)}\mathbf 1[\hat y(z)=y] = \mathbb E_{(x,y)\sim\rho}\,p_\theta(y\mid x). \] Max-likelihood wants instead: \[ J_{\mathrm{ML}} = \mathbb E_{(x,y)\sim\rho}\,\log p_\theta(y\mid x) = \mathbb E_{(x,y)\sim\rho}\,\log\mathbb E_{z\sim m_\theta(\cdot\mid x)} \mathbf 1[\hat y(z)=y]. \]

Continuous regression

Specialize to a Gaussian noise model with \(\sigma=1\): \[ l(y,z)=\hat P(y\mid z)=\mathcal N(\hat y(z))(y) = \frac{1}{\sqrt{2\pi}} \exp\left[-\frac{(y-\hat y(z))^2}{2}\right]. \] Then \[ J(\theta) = \mathbb E_{(x,y)\sim\rho} \,\log\mathbb E_{z\sim m_\theta(\cdot\mid x)} \left[\exp\left(-\frac{(y-\hat y(z))^2}{2}\right)\right] +\text{const}. \]

An intuitive per-rollout reward is negative MSE: \[ r(y,z):=-\frac{(y-\hat y(z))^2}{2}. \] A direct analogue would average these rollout rewards: \[ \mathbb E_{(x,y)\sim\rho}\,\mathbb E_{z\sim m_\theta(\cdot\mid x)}\,r(y,z). \] Maximum likelihood instead optimizes \[ \mathbb E_{(x,y)\sim\rho}\,\log\mathbb E_{z\sim m_\theta(\cdot\mid x)}\,e^{r(y,z)} \] this is (up to constants) a log-sum-exp, rather than a simple average, over per-rollout MSE-derived terms. So within each sample, the objective reinforces the most successful trajectories; we recover this same structure in the general form below.

Jenson and Taylor

Fix \((x,y)\) and suppress dependencies to reduce clutter: \[ p := p_\theta(y\mid x)=\mathbb E_{z\sim m_\theta(\cdot\mid x)} l(y,z). \]

For \(p\in(0,1]\), Taylor-expanding about \(p=1\) yields \[ \log p = -\sum_{k=1}^\infty \frac{(1-p)^k}{k}. \] The expansion is about \(p=1\) (success), so \(p\to 0\) implies greater deviation between the first (direct) and full (maximum-likelihood) degrees: another perspective on larger improvements for harder tasks.

Truncating to degree \(D\) gives the compute-indexed MaxRL objective \[ \begin{equation} J_D(p) := -\sum_{k=1}^D \frac{(1-p)^k}{k}. \label{eq:j-truncated} \end{equation} \]

  • \(D=1\): \(J_1(p)=-(1-p)=p-1\), that is RL / pass-rate training up to an additive constant.
  • \(D\to\infty\): \(J_D(p)\to\log p\), that is exact maximum likelihood.

Differentiating: \[ \nabla_\theta J_D(p_\theta) = \sum_{k=1}^D (1-p)^{k-1} \cdot \nabla p =: w_D(p)\cdot \nabla p \] \[ \begin{equation} w_D(p)=\sum_{k=0}^{D-1}(1-p)^k =\frac{1-(1-p)^D}{p}. \label{eq:weight} \end{equation} \] As \(D\to\infty\), \(w_D(p)\to 1/p\), recovering ML’s inverse-probability reweighting. The log-derivative trick on \(p=\mathbb E_{z\sim m_\theta}[l(y,z)]\) gives \[ \nabla_\theta p = \mathbb E_{z\sim m_\theta(\cdot\mid x)}\big[l(y,z)\,\nabla_\theta\log m_\theta(z\mid x)\big] =\mathbb E[lS], \] so \[ \begin{equation} \nabla_\theta J_D(p) = w_D(p)\,\mathbb E_{z\sim m_\theta(\cdot\mid x)}\big[l(y,z)\,S(x,z)\big]. \label{eq:gradient-main} \end{equation} \]

We can read off two qualitative behaviors:

Remark 1 (per-prompt): inside \(\mathbb E[lS]\), trajectories with larger likelihood \(l(y,z)\) get more weight.

  • Binary case: only successful rollouts contribute (\(l\in\{0,1\}\)).
  • Gaussian regression: \(l\propto \exp(-\mathrm{MSE}/(2\sigma^2))\) so the best rollouts dominate.

Remark 2 (across prompts): the scalar multiplier \(w_D(p)\) increases when \(p\) is small (hard prompts). In the ML limit \(D\to\infty\), \(w_D(p)=1/p\) reproduces the inverse-pass-rate reweighting.

Gradient estimators

All’s great: we have a principled objective. How are we going about optimizing it?

Binary case

In the binary setting \(l(y,z)\in\{0,1\}\), draw \(N\) trajectories \(z_1,\dots,z_N\sim m_\theta(\cdot\mid x)\), define \[ l_j:=l(y,z_j),\qquad S_j:=\nabla_\theta\log m_\theta(z_j\mid x),\qquad K:=\sum_{j=1}^N l_j. \]

  • REINFORCE (pass@1) uses \[ \hat g_{\mathrm{RL}}=\frac{1}{N}\sum_{j=1}^N l_j S_j, \] which is unbiased for \(\nabla_\theta\,\mathrm{pass@}1(x)\).

  • MaxRL’s key estimator averages scores over successful trajectories only, \[ \begin{equation} \hat g_N^{\mathrm{bin}}(x) := \begin{cases} \frac{1}{K}\sum_{j=1}^N l_j S_j, & K\ge 1,\\ 0, & K=0. \end{cases} \label{eq:binary-estimator} \end{equation} \]

Conditioning on \(K\geq 1\), \[ \mathbb E_z\big[\hat g_N^{\mathrm{bin}}(x)\mid K\geq 1\big] = \mathbb E_z[S\mid l=1] = \dfrac{\mathbb E[l\cdot S]}{\mathbb E[l]} = \dfrac{\nabla p}{p} = \nabla \log p. \] It’s an unbiased ML estimator, conditional on \(K\geq 1\)! The bias comes from \(K=0\), which occurs with probability \((1-p)^N\). Substituting recovers exactly the gradient form: \[ \mathbb E_z\big[\hat g_N^{\mathrm{bin}}(x)\big] = (1-(1-p)^N) \nabla \log p = w_N(p)\cdot \nabla p = \nabla J_N(p). \]

Generalization

Drop the assumption \(l\in\{0,1\}\) and keep only what the derivation above actually used:

  • \(l_j := l(y,z_j)\in[0,1]\) is a per-rollout likelihood/reward signal,
  • \(p = \mathbb E[l]\),
  • \(\nabla_\theta p = \mathbb E[lS]\),
  • \(\nabla_\theta J_D = w_D(p)\,\nabla_\theta p\).

We want to estimate the last quantity using \(N\) iid rollout samples, with \(1 \le D \le N\). The obstacle is subtle but standard:

  • We can estimate \(p\) and \(\nabla_\theta p\) unbiasedly from samples.
  • But \(w_D(p)\nabla_\theta p\) is a product of unknowns.
  • Plugging in sample estimates makes bias because the factors are correlated.

The key is the leave-one-out trick. Use one sample to estimate \(\nabla_\theta p\), the remaining \(N-1\) samples to estimate \(w_D(p)\), and average over all leave-one-outs. The product factorizes because samples are conditionally independent.

We only need a known upper bound \(L \geq \max l\): set \(\sigma_j := l_j/L\), then \(\log\mathbb E[\sigma_j] = \log p - \log L\) differs by a \(\theta\)-independent constant, so the gradient is unchanged and all derivations apply with \((l_j, p) \mapsto (\sigma_j, \sigma_\theta)\). For Gaussian regression, \(L = (2\pi\sigma^2)^{-1/2}\).

Formally, suppose we have an estimator subroutine \(\omega_j\), built from \(\{l_k\}_{k\ne j}\) only, such that \[ \mathbb E[\omega_j] = w_D(p). \] We know \(l_j S_j\) is an unbiased estimator for \(\nabla p = \mathbb E[l\cdot S]\), so the leave-one-out product \(\omega_j l_j \cdot S_j\) is unbiased for \(w_D(p)\nabla_\theta p\). Averaging over \(j\) gives the final estimator: \[ \begin{equation} \hat g_D(x,y) := \frac{1}{N}\sum_{j=1}^N \omega_j\,l_j\,S_j. \label{eq:general-estimator} \end{equation} \] This is, again, a simple reweighted average of the rollout scores. To reduce variance, we can subtract any constant baseline (since \(\mathbb E[S]=0\)).

It remains to solve: given iid samples \((l_0, \dots, l_{N-1})\), estimate \(w_D(p)=\sum_{k=0}^{D-1}(1-p)^k\).

  • Taking \(D=N\), it suffices to obtain estimators for \((1-p)^k\) for all \(1\leq k\leq N-1\).
  • This is a textbook problem with a known MVUE (minimum-variance unbiased estimator). See Gradient Estimator for the numerically stable \(O(BRD)\) prefix-suffix-scan implementation used in this repo.

Generalized baseline subtraction

Here, we explain the semantics of MaxRLEstimatorConfig.subtract_baseline flag.

The leave-one-out construction admits more than a constant baseline. Since \(\omega_j\) is built from the peers \(z_{-j} := (z_i)_{i \ne j}\) only, any \(b_j\) measurable with respect to \(z_{-j}\) preserves unbiasedness, and replacing the per-rollout coefficient \(c_j := \omega_j l_j\) by \(c_j - b_j\) leaves an unbiased estimator of \(\nabla_\theta J_D(p)\). Consider the peer-only baseline \[ b_j := \omega_j\,\bar l_{-j}, \qquad \bar l_{-j} := \frac{1}{N-1}\sum_{i\ne j} l_i, \] and the centered coefficient becomes \[ a_j := c_j - b_j = \omega_j\,(l_j - \bar l_{-j}) = \omega_j \cdot \frac{N}{N-1}\,(l_j - \bar l), \] with \(\bar l := \frac{1}{N}\sum_i l_i\), via the identity \(l_j - \bar l_{-j} = \frac{N}{N-1}(l_j - \bar l)\). The baseline-subtracted estimator \[ \hat g_D^{\mathrm c}(x, y) := \frac{1}{N}\sum_{j=1}^N a_j\,S_j \] is unbiased for \(\nabla_\theta J_D(p)\), and strip the common \(\omega_j p\) level shared across rollouts.

A tempting alterantive is the leave-one-out average of \((\omega l)_{-j}\), but this quantity is measurable w.r.t. \(z_j\) because \(\omega_{k\neq j}\) is dependent upon \(z_j\), resulting in a biased estimator.

Reference implementation: src/maxrl_estimator.py.

We use the generalized MaxRL estimator in its leave-one-out form. Fix one batch row \((x, y)\), let \(L > 0\) be a known upper bound on the likelihood function \(l\), and draw \(R\) iid rollouts \(z_1, \dots, z_R \sim m_\theta(\cdot \mid x)\). Define detached per-rollout likelihoods, their normalizations, and score vectors \[ l_j := l(y, z_j) \in [0, L], \quad \sigma_j := l_j / L \in [0, 1], \quad S_j := \nabla_\theta \log m_\theta(z_j \mid x). \] Further define the marginal normalized likelihood and the weight function \[ \sigma_\theta := \mathbb{E}[\sigma_j] \in (0, 1], \qquad w_D(\sigma_\theta) := \sum_{k=0}^{D-1} (1 - \sigma_\theta)^k. \]

Population objective

The degree-\(D\) MaxRL objective is the degree-\(D\) Maclaurin truncation of \(\log \sigma_\theta\) about \(\sigma_\theta = 1\): \[ J_D(\theta) := -\sum_{k=1}^{D} \frac{(1 - \sigma_\theta)^k}{k}, \qquad \nabla_\theta J_D = w_D(\sigma_\theta) \, \mathbb{E}[\sigma_j \, S_j]. \] As \(D \to \infty\), \(J_D \to \log \sigma_\theta\) and the gradient recovers the exact log-likelihood gradient; at finite \(D\) the gradient residual is the geometric factor \(1 - (1 - \sigma_\theta)^D\).

Leave-one-out estimator

The generalized leave-one-out estimator has the form \[ \hat{g}_D(x, y) = \frac{1}{R} \sum_{j=1}^R \omega_j \, \sigma_j \, S_j, \] where each \(\omega_j\) is built from the peer rollouts \(k \neq j\) only and satisfies \[ \mathbb{E}[\omega_j] = w_D(\sigma_\theta). \]

Formulating the problem

Define the per-rollout complements \[ a_j := 1 - \sigma_j \in [0, 1] \implies w_D(\sigma_\theta) = \sum_{k=0}^{D-1} \mathbb{E}[a_j]^k. \] For a list \((a_1, \dots, a_R) \in [0, 1]^R\), its \(k\)-th elementary symmetric polynomial is the sum of all size-\(k\) products: \[ e_k(a_1, \dots, a_R) := \sum_{1 \le i_1 < \cdots < i_k \le R} a_{i_1} \cdots a_{i_k}, \qquad e_0 := 1. \]

Fix index \(j\). Its canonical leave-one-out peer set is \[ C_j := \{1, \dots, j-1, j+1, \dots, R\}. \] We care about the normalized elementary symmetric polynomial for each element on its leave-one-out peer set, and, in particular, its sum; our gradient estimator depends on this weighting: \[ \omega_j = \sum_{k=0}^{D-1} \frac{e_k\bigl((a_i)_{i \in C_j}\bigr)}{\binom{R-1}{k}} \] This yields a standalone programming problem.

Input. A batched tensor \(a \in [0, 1]^{B \times R}\) and an integer \(1 \le D \le R\).

Output. A batched tensor \(\omega \in \mathbb{R}^{B \times R}\) with entries \[ \omega_{b, j} = \sum_{k=0}^{D-1} \frac{e_k\bigl((a_{b, i})_{i \in C_j}\bigr)}{\binom{R-1}{k}}. \]

Target complexity. An exact or mathematically equivalent formulation with:

  • \(O(BRD)\) time, \(O(BRD)\) memory.
  • no subtraction of nearly equal \(O(1)\) or larger terms.

The last requirement is the key numerical design constraint. A natural but unstable route is to compute full-sample coefficients and then “peel off” rollout \(j\) by subtraction. We empirically found that this leads to significant numerical errors for \(R \geq 32\), and digit-significance dependence grows approximately linearly in the number of rollouts.

State vectors and matrix view

Instead, we define states that are already normalized by the final peer count \(R - 1\). For any canonical subset \(I \subseteq \{1, \dots, R\}\), define the state vector \[ x(I) := \bigl(x_0(I), \dots, x_{D-1}(I)\bigr)^\top, \quad x_k(I) := \frac{e_k\bigl((a_i)_{i \in I}\bigr)}{\binom{R-1}{k}}. \]

Two basic facts make this a good state space:

  1. \(x_0(I) = 1\).
  2. Because each \(a_i \in [0, 1]\), every forward-state coordinate is bounded \(0 \le x_k(I) \le 1\).

Now suppose \(I\) is a canonical subset and we append one new complement value \(a\). Using \[ e_k(I \cup \{a\}) = e_k(I) + a \, e_{k-1}(I), \] we obtain the fixed-denominator recurrence over appending elements to the canonical set \[ x_0' = x_0, \quad x_k' = x_k + \frac{k}{R-k} \, a \, x_{k-1}, \qquad k = 1, \dots, D-1. \] Package the update as multiplication by a lower-bidiagonal matrix \(M(a) \in \mathbb{R}^{D \times D}\): \[ x' = M(a) \, x \quad \text{ where } \quad M(a)_{k, k} = 1,\quad M(a)_{k, k-1} = \frac{k}{R-k} \, a \]

With the empty-set initial state \[ e_0 := (1, 0, \dots, 0)^\top, \] the state for any canonical prefix \(I = \{1, \dots, j\}\) is obtained by repeated application of these matrices.

Prefix-suffix scans

Define the forward prefix states so that \(\alpha_j = x(\{1, \dots, j\})\): \[ \alpha_0 := e_0, \qquad \alpha_j := M(a_j) \, \alpha_{j-1}, \qquad j = 1, \dots, R. \] Similarly define the suffix covectors which encode the “suffix-and-sum” operation: \[ \beta_R^\top := \mathbf{1}^\top, \qquad \beta_{j-1}^\top := \beta_j^\top M(a_j), \qquad j = R, \dots, 1, \]

Now fix rollout \(j\). The leave-one-out peer set \(C_j\) is the union of the canonical prefix before \(j\) and the canonical suffix after \(j\). Its state vector is therefore \[ x(C_j) = M(a_R) \cdots M(a_{j+1}) \, \alpha_{j-1} \implies \omega_j = \mathbf{1}^\top x(C_j) = \beta_j^\top \alpha_{j-1}. \]

Algorithm

For one batch row, the algorithm is:

  1. Convert normalized likelihoods to complements \(a_j = 1 - \sigma_j\).
  2. Run a forward scan over \(j = 1, \dots, R\) using the lower-bidiagonal update \(M(a_j)\).
  3. Run a backward scan over \(j = R, \dots, 1\) using the same update.
  4. Form all leave-one-out weights via \(\omega_j = \beta_j^\top \alpha_{j-1}\).

Each matrix-vector or covector-matrix update touches only adjacent state coordinates, so each scan step costs \(O(D)\). The full batched computation therefore has the target complexity \(O(BRD)\).
