MaxRL gradient estimator details

Reference implementation: src/maxrl_estimator.py.

We use the generalized MaxRL estimator in its leave-one-out form. Fix one batch row \((x, y)\), let \(L > 0\) be a known upper bound on the likelihood function \(l\), and draw \(R\) iid rollouts \(z_1, \dots, z_R \sim m_\theta(\cdot \mid x)\). Define detached per-rollout likelihoods, their normalizations, and score vectors \[ l_j := l(y, z_j) \in [0, L], \quad \sigma_j := l_j / L \in [0, 1], \quad S_j := \nabla_\theta \log m_\theta(z_j \mid x). \] Further define the marginal normalized likelihood and the weight function \[ \sigma_\theta := \mathbb{E}[\sigma_j] \in (0, 1], \qquad w_D(\sigma_\theta) := \sum_{k=0}^{D-1} (1 - \sigma_\theta)^k. \]

Population objective

The degree-\(D\) MaxRL objective is the degree-\(D\) Maclaurin truncation of \(\log \sigma_\theta\) about \(\sigma_\theta = 1\): \[ J_D(\theta) := -\sum_{k=1}^{D} \frac{(1 - \sigma_\theta)^k}{k}, \qquad \nabla_\theta J_D = w_D(\sigma_\theta) \, \mathbb{E}[\sigma_j \, S_j]. \] As \(D \to \infty\), \(J_D \to \log \sigma_\theta\) and the gradient recovers the exact log-likelihood gradient; at finite \(D\) the gradient residual is the geometric factor \(1 - (1 - \sigma_\theta)^D\).

Leave-one-out estimator

The generalized leave-one-out estimator has the form \[ \hat{g}_D(x, y) = \frac{1}{R} \sum_{j=1}^R \omega_j \, \sigma_j \, S_j, \] where each \(\omega_j\) is built from the peer rollouts \(k \neq j\) only and satisfies \[ \mathbb{E}[\omega_j] = w_D(\sigma_\theta). \]

Formulating the problem

Define the per-rollout complements \[ a_j := 1 - \sigma_j \in [0, 1] \implies w_D(\sigma_\theta) = \sum_{k=0}^{D-1} \mathbb{E}[a_j]^k. \] For a list \((a_1, \dots, a_R) \in [0, 1]^R\), its \(k\)-th elementary symmetric polynomial is the sum of all size-\(k\) products: \[ e_k(a_1, \dots, a_R) := \sum_{1 \le i_1 < \cdots < i_k \le R} a_{i_1} \cdots a_{i_k}, \qquad e_0 := 1. \]

Fix index \(j\). Its canonical leave-one-out peer set is \[ C_j := \{1, \dots, j-1, j+1, \dots, R\}. \] We care about the normalized elementary symmetric polynomial for each element on its leave-one-out peer set, and, in particular, its sum; our gradient estimator depends on this weighting: \[ \omega_j = \sum_{k=0}^{D-1} \frac{e_k\bigl((a_i)_{i \in C_j}\bigr)}{\binom{R-1}{k}} \] This yields a standalone programming problem.

Input. A batched tensor \(a \in [0, 1]^{B \times R}\) and an integer \(1 \le D \le R\).

Output. A batched tensor \(\omega \in \mathbb{R}^{B \times R}\) with entries \[ \omega_{b, j} = \sum_{k=0}^{D-1} \frac{e_k\bigl((a_{b, i})_{i \in C_j}\bigr)}{\binom{R-1}{k}}. \]

Target complexity. An exact or mathematically equivalent formulation with:

  • \(O(BRD)\) time, \(O(BRD)\) memory.
  • no subtraction of nearly equal \(O(1)\) or larger terms.

The last requirement is the key numerical design constraint. A natural but unstable route is to compute full-sample coefficients and then “peel off” rollout \(j\) by subtraction. We empirically found that this leads to significant numerical errors for \(R \geq 32\), and digit-significance dependence grows approximately linearly in the number of rollouts.

State vectors and matrix view

Instead, we define states that are already normalized by the final peer count \(R - 1\). For any canonical subset \(I \subseteq \{1, \dots, R\}\), define the state vector \[ x(I) := \bigl(x_0(I), \dots, x_{D-1}(I)\bigr)^\top, \quad x_k(I) := \frac{e_k\bigl((a_i)_{i \in I}\bigr)}{\binom{R-1}{k}}. \]

Two basic facts make this a good state space:

  1. \(x_0(I) = 1\).
  2. Because each \(a_i \in [0, 1]\), every forward-state coordinate is bounded \(0 \le x_k(I) \le 1\).

Now suppose \(I\) is a canonical subset and we append one new complement value \(a\). Using \[ e_k(I \cup \{a\}) = e_k(I) + a \, e_{k-1}(I), \] we obtain the fixed-denominator recurrence over appending elements to the canonical set \[ x_0' = x_0, \quad x_k' = x_k + \frac{k}{R-k} \, a \, x_{k-1}, \qquad k = 1, \dots, D-1. \] Package the update as multiplication by a lower-bidiagonal matrix \(M(a) \in \mathbb{R}^{D \times D}\): \[ x' = M(a) \, x \quad \text{ where } \quad M(a)_{k, k} = 1,\quad M(a)_{k, k-1} = \frac{k}{R-k} \, a \]

With the empty-set initial state \[ e_0 := (1, 0, \dots, 0)^\top, \] the state for any canonical prefix \(I = \{1, \dots, j\}\) is obtained by repeated application of these matrices.

Prefix-suffix scans

Define the forward prefix states so that \(\alpha_j = x(\{1, \dots, j\})\): \[ \alpha_0 := e_0, \qquad \alpha_j := M(a_j) \, \alpha_{j-1}, \qquad j = 1, \dots, R. \] Similarly define the suffix covectors which encode the “suffix-and-sum” operation: \[ \beta_R^\top := \mathbf{1}^\top, \qquad \beta_{j-1}^\top := \beta_j^\top M(a_j), \qquad j = R, \dots, 1, \]

Now fix rollout \(j\). The leave-one-out peer set \(C_j\) is the union of the canonical prefix before \(j\) and the canonical suffix after \(j\). Its state vector is therefore \[ x(C_j) = M(a_R) \cdots M(a_{j+1}) \, \alpha_{j-1} \implies \omega_j = \mathbf{1}^\top x(C_j) = \beta_j^\top \alpha_{j-1}. \]

Algorithm

For one batch row, the algorithm is:

  1. Convert normalized likelihoods to complements \(a_j = 1 - \sigma_j\).
  2. Run a forward scan over \(j = 1, \dots, R\) using the lower-bidiagonal update \(M(a_j)\).
  3. Run a backward scan over \(j = R, \dots, 1\) using the same update.
  4. Form all leave-one-out weights via \(\omega_j = \beta_j^\top \alpha_{j-1}\).

Each matrix-vector or covector-matrix update touches only adjacent state coordinates, so each scan step costs \(O(D)\). The full batched computation therefore has the target complexity \(O(BRD)\).
