How to read this report

Best checkpoint means the checkpoint selected by minimum validation mean-prediction MAE. The best columns show all metrics at that same checkpoint. Final columns show the last validation epoch of a completed run. Test columns use clean held-out labels at the selected checkpoint. Historical runs did not retain final-epoch test models; final-epoch test metrics are unavailable.

Curves are validation metrics. Means and sample SDs describe completed training seeds, not confidence intervals or dataset uncertainty. Exact best epochs, metric-specific extrema, status and source commits are available through each row's “Runs” button. Scalar regression has no label NLL; scalar Spearman ranks its continuous prediction, while categorical Spearman ranks the distribution median.

The 1024×200 extension matches the 3,200 training updates of 4096×50, while 1024×50 uses 800 updates. Validation is evaluated more frequently in the longer small-subset run. Noise is rounded and clipped to ages 0–99; SNR is 10 log10(clean-age variance / realized perturbation MSE). Optimization seeds and noise-realization seeds remain distinct dimensions.

Rows are kept separate across training-source cohorts, data splits, subsets, horizons, learning-rate schedules and noise realizations. Exact RGB duplicates were removed before splitting; this is not a subject-disjoint or near-duplicate-disjoint benchmark.
