# Shared library code

Importable as the `src` package.

- `config/`: utilities for defining, composing, and visualizing stateless configs.
- `data/`: dataset construction, dataloading, parquet I/O.
- `model/`: model definitions and optimizers.
- `experiments/`: per-experiment training/analysis modules (e.g. `bag_of_words/`).
- `metrics.py`: shared metrics.
