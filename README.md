# MaxRL-statistics

Research code for maximum-likelihood reinforcement learning for statistical estimation.

Repository layout:
- `docs`: writeup artifacts (autogenerated)
- `src`: shared library code
- `theory`: markdown context for theory
- `experiments`: experiment code.
    - `artifacts`: locally cached experiment results, graphics etc.
- `writeup`:

### Environment setup

System requirements: a machine with nvidia GPUs.

Install [uv](https://docs.astral.sh/uv/getting-started/installation/):

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

Then install dependencies:

```bash
uv sync --dev
```

### Locally accessing the writeup

`cd` to `writeup/`, then run `quarto preview`
